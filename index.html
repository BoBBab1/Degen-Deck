Exact vs. approximate — the Ethereum rank comes from a free public block explorer that lists QANX holders sorted by balance, so your position is read directly off that list (accurate within its top 1,000). BSC has no equivalent free public holder-list API — full rank data there is a paid feature on BscScan — so your BSC rank is estimated using a Zipf's-law-style guess: it compares your balance to the largest known holder and assumes the drop-off between holders is steep, the way real token distributions usually are. Treat the BSC number as a rough order-of-magnitude, not a verified position.
